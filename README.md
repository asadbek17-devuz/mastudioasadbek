# mastudio.asadbek

Personal portfolio of Asadbek — Software Engineer & Web Developer.

Built with Next.js (App Router), TypeScript, Tailwind CSS v4, shadcn/ui structure, Framer Motion, GSAP and Matter.js. Available in English, Uzbek and Russian.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Edit content

- `lib/data.ts` — links, images, numbers, projects, stack, startups, journey
- `lib/i18n/dictionaries/{en,uz,ru}.ts` — all texts in three languages
